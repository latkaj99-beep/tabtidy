# Changelog

All notable changes to TabTidy are documented here.
Format based on [Keep a Changelog](https://keepachangelog.com/), versioning follows [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-11-09

### Added
- Popup listing all open tabs with favicon, title, pinned/audio markers and last-used time.
- Views: by topic, by domain, by window, or no grouping.
- 10 topic categories: Work, Dev, Social, Video, Shopping, News, Learning, AI, Email, Other.
- Search by title or URL.
- Status filters: idle over 30 minutes, duplicates, sleeping, playing audio, pinned.
- Selection per tab, per group, or all filtered tabs.
- Bulk actions: group into a named Chrome tab group, sleep (discard), close with confirmation.
- One-click auto-group of all unpinned tabs by topic, and ungroup all.
- Background auto-close of unused tabs with configurable idle time (default 60 min, minimum 5).
- Option to sleep idle tabs instead of closing them.
- Protection for pinned tabs, audio tabs, grouped tabs and whitelisted domains.
- Recently auto-closed list (last 50) with one-click reopen.
- Logo, toolbar icons and indigo / violet / teal themed UI.
